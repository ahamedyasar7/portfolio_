PROJECT OVERVIEW

Agrismart1.0 is an IoT-based smart agriculture monitoring system designed to bring multiple agricultural parameters into one connected platform.

The system uses an ESP32 and multiple sensors to monitor soil moisture, temperature, humidity, tank water level and rainfall. The collected information is displayed through a web dashboard for real-time monitoring and pump control.

An AI layer provides rain prediction and agriculture-related recommendations using the available information, helping turn raw sensor data into useful insights.

02

HOW I GOT THE IDEA

I got the idea for Agrismart1.0 from the need to make agriculture smarter using technology.

I wanted to combine my interests in IoT, embedded systems, web development, and AI into one practical project.

I was particularly interested in how sensors could be used to understand field conditions and how AI could help farmers make better irrigation decisions.

03

THE PROBLEM I WANTED TO SOLVE

Farmers need to continuously monitor factors such as soil moisture, temperature, humidity, rainfall, and water availability.

Making irrigation decisions manually can sometimes lead to unnecessary water usage.

I wanted to build a system that could provide these details in one place and give useful suggestions based on the collected information.

MY EXPERIENCE WHILE BUILDING IT

Building Agrismart1.0 gave me experience in connecting hardware with software.

I worked with the ESP32, sensors, relay, pump, backend APIs, and web dashboard.

HOW I SOLVED THEM

I solved the problems by testing each component separately before integrating everything.

I checked sensor readings individually, tested ESP32 communication, verified API requests and responses, and connected the components step by step.

I also used debugging and repeated testing to identify whether an issue was coming from the hardware, backend, or frontend.
